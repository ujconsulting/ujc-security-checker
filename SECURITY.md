# Security policy

Please report vulnerabilities privately. **Do not open a public issue** for a security problem.

Use **private vulnerability reporting**: "Report a vulnerability" in the
[Security tab](https://github.com/ujconsulting/ujc-security-checker/security/advisories/new) of this repository.

We acknowledge reports within 5 working days and keep you updated until the issue is resolved.
Only the latest release on the default branch is supported. We are happy to coordinate disclosure
and to credit you in the advisory.
